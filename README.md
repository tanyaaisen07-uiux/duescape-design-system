# Duescape: Design System

A living style guide for Duescape, a subscription and budget tracker mobile app. Client project, Netherlands. Built as a single self-contained HTML page: no frameworks, no build step, just design tokens and live components.

**Live demo:** https://tanyaaisen07-uiux.github.io/duescape-design-system/

## What's inside
- **Design principles:** Clarity First, Action Over Analysis, Familiar by Default
- **Color:** full palette with a Light / Dark theme switch
- **Typography:** 8-step type scale (Inter / SF Pro), tabular figures for money
- **Geometry:** radius scale and a 4px spacing grid
- **Components:** balance card, action tiles, payment rows, badges, toggles, charts, all rendered live from CSS variables
- **Iconography:** line icons, 1.5 to 2px stroke, container rules
- **Components in context:** components shown on a mini dashboard mock with the role each one plays
- **Developer tokens:** copy-paste CSS variables for both themes
